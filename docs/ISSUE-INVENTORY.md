필요한 상황에서 막히고, 이미 나간 빌드에 들어 있다. 인증 셸(NM-407) 영역이라

**③은 아직 확인하지 못했다.** Play Console 「앱 콘텐츠」 진입을 네 번 시도했으나 URL 이 앱
목록으로 리다이렉트되고 좌측 nav 항목도 눌리지 않았다. 사전 검사를 통과해 검토로 넘어간 것을
보면 채워져 있을 가능성이 높지만(0.2.2 의 광고 ID 선언 누락은 바로 그 사전 검사가 잡았다 — ⑨),

### 곁가지 — 이 파일의 규칙과 내용이 어긋난다

머리말은 「고치면 이 파일에서 지운다」인데 ⑥~⑩(워치 만료 화면 · 서명 지문 · SME · 광고 ID ·
R8)은 전부 **해결된 건**이다. 지우기엔 아까운 함정 기록이다.

원인은 **「아직 못 고친 문제」와 「다시 밟을 함정」을 한 파일에 섞어 둔 것**이다.
둘을 가르거나(`KNOWN-ISSUES` / `PITFALLS`), 머리말을 실제에 맞게 고친다.
