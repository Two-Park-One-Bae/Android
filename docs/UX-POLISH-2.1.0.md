## 전체 테스트 때 볼 것 (1번)

1. 열린 칩을 다시 누르면 닫힌다 — 길게 눌러도
2. 열린 채 다른 칩을 누르면 한 번에 그 칩 메뉴로 넘어간다
3. 빈 곳(후보 목록 등)을 누르면 닫힌다
4. 메뉴에서 고른 직후 같은 칩을 누르면 다시 열린다
5. 뒤로가기는 메뉴만 닫는다
